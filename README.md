##  kurdi (بادینی)
ئەڤ پڕۆژەیە تایبەتە بە کیبۆردا **VIP Kurdish Keyboard** یا پێشکەفتی بۆ سیستەمێ ئایفۆن (iOS). ڤی بەرنامەی پشتاڤانیا پیتێن کوردی (بادینی و سۆرانی)، لێدانا هەستیار (Haptic)، و پشتڕووکێن تایبەت دکەت.

### 📱 چاوا کیبۆردێ ل ئایفۆنێ زێدە کەین؟ (How to Add Keyboard on iOS)
1. بچە ناڤ **Settings** (مۆبایلێ).
2. پاشان بچە بۆ **General** > **Keyboard** > **Keyboards**.
3. کلیک ل سەر **Add New Keyboard...** بکە.
4. کیبۆردا **VIP Kurdish Keyboard** ژ لیستەیێ هەڵبژێرە.
5. ل سەر ناڤێ کیبۆردێ کلیک بکە و **Allow Full Access** چەک بکە (بۆ کارپێکرنا تەڤایا تایبەتمەندیان).
