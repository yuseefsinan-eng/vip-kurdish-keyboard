# ⭐ VIP Kurdish Keyboard (iOS)

**The Ultimate Custom Kurdish Keyboard for iPhone & iOS**  
کۆد و پڕۆژەیا کیبۆردا ڤیپ یا کوردی بۆ ئایفۆن و مۆبایلان.

## 🖤 kurdi (بادینی / سۆرانی)
نەڤ پڕۆژەیە تایبەتە بە کیبۆردا **VIP Kurdish Keyboard** یا پێشکەفتی بۆ سیستەمێ ئایفۆن (iOS). ڤی بەرنامەی پشتاڤانیا پیتێن کوردی (بادینی و سۆرانی)، لیدانا هەستیار (Haptic)، و پشترووکین تایبەت دکەت.

## 🚀 Key Features Inside App:
- **Native Kurdish Layout:** Full support for Badini and Sorani characters (ێ، ڤ، چ، ژ، پ، گ).
- **VIP Onyx & Gold Theme:** Modern glassmorphism dark styling.
- **Haptic Feedback:** Professional tactile response on every key press.
- **Complete Emojis & World Flags:** All official iPhone emojis and global country flags included.
- **Custom Backgrounds & Uploads:** Set photos from your gallery as the keyboard background or custom emojis.

## ⚙️ How to Add on iOS (Keyboard on iOS):
1. بچە ناف **Settings** (مۆبایلی).
2. پاشان بچە بۆ **General > Keyboard > Keyboards**.
3. کلیک ل سەر **Add New Keyboard...** بکە.
4. کیبۆردا **VIP Kurdish Keyboard** ژ لیستەیی هەلبژێرە.
5. ل سەر ناڤێ کیبۆردی کلیک بکە و **Allow Full Access** چەک بکە.
